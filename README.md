# 🩺 Skin Disease Detection using Deep Learning

This project is a deep learning-based skin disease classification system that uses Convolutional Neural Networks (CNNs) to detect and classify multiple types of skin diseases from dermatoscopic images. It aims to provide a fast, accessible, and accurate tool to support dermatologists and healthcare professionals.

## 📌 Features

- ✅ Trained CNN model to classify common skin diseases with high precision.
- 🧠 Applied image preprocessing techniques such as resizing, normalization, and augmentation.
- 📈 Achieved 79% accuracy after hyperparameter tuning on a limited dataset.
- 🧪 Built using Python and TensorFlow, integrated with Pandas and NumPy for data handling.
- 🌐 Future plans include deploying via Flask/Streamlit for real-time predictions.

---

## 🛠️ Tech Stack

- **Language**: Python  
- **Libraries**: TensorFlow, Keras, Pandas, NumPy, Matplotlib  
- **Tools**: Jupyter Notebook  
- **Model**: Convolutional Neural Network (CNN)

---

## 🧪 Model Workflow

1. **Data Collection & Cleaning**  
   - Imported dataset with skin disease images  
   - Preprocessed images (resized, normalized, augmented)

2. **Model Building**  
   - CNN built with multiple convolutional and pooling layers  
   - Used ReLU activation and dropout for regularization  
   - Final dense layers for multi-class classification

3. **Model Training & Evaluation**  
   - Trained model using cross-entropy loss and Adam optimizer  
   - Validated on test set with accuracy ~79%  
   - Visualized loss and accuracy trends
